**גרסה ראשונה לניסיון (pre-release).**

| קובץ | מה זה |
|---|---|
| `Asmon-*-Setup.exe` | מתקין אחד עם הכול לכתיבה, בנייה, דיבוג והנדסה לאחור. אין בו כלים חיצוניים כבדים. |
| `Asmon-*-portable.zip` | אותו תוכן בגרסה ניידת: מחלצים ומריצים את `asmon.exe`. |
| `Asmon-x86-tools.zip` | אופציונלי: כלי 32 ביט. לחלץ לתיקיית אסמון. |
| `Asmon-LLVM-tools.zip` | אופציונלי: LLVM לבניית תוכניות לינוקס בלי WSL. לחלץ לתיקיית אסמון. |
| `Asmon-RE-tools.zip` | אופציונלי: ‏Ghidra, ‏Cutter, ‏x64dbg, ‏ImHex. לחלץ לתיקייה `tools` שבתיקיית אסמון. |

לכל קובץ יש `.sha256` ליד.

⚠️ המתקין לא חתום דיגיטלית, ולכן SmartScreen יציג אזהרה. כדי להמשיך: More info ← Run anyway.

הגרסאות המדויקות של כל הכלים שבפנים נמצאות ב-`licenses\VERSIONS.txt`. הרישיונות מפורטים ב-`THIRD_PARTY.md`.
