Source for GPL components: Asmon's own source is in this repository (a git tag per release). For bundled third-party GPL programs the corresponding source is at the upstream release of the exact version listed in `licenses/VERSIONS.txt`; if a link stops working, open an issue and the source will be provided.

## Notepad++ colour themes

The colour themes offered in Settings → Colors (Bespin, Black board, Choco, DansLeRuSH-Dark, DarkModeDefault, Deep Black,
Hello Kitty, HotFudgeSundae, Mono Industrial, Monokai, MossyLawn, Navajo, Obsidian, Plastic Code Wrap, Solarized,
Solarized-light, Twilight, Vibrant Ink, Zenburn, khaki, vim Dark Blue) are converted from the theme files shipped with
Notepad++ (https://github.com/notepad-plus-plus/notepad-plus-plus, GPL-3.0, `PowerEditor/installer/themes`).
Each theme keeps the licence and credit of its original author, as stated in the header of its source file
(for example Monokai: MIT, Fabio Zendhi Nagao; Solarized: Ethan Schoonover, MIT; Zenburn: Jani Nurminen).
The table is generated by `tools/gen_npp_themes.py` into `nppthemes.h`.
