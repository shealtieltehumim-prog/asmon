# אסמון — סביבת פיתוח לאסמבלי, בעברית

אסמון היא סביבת פיתוח מינימלית לאסמבלי: כותבים, בונים, מריצים, מדבגים ועושים הנדסה לאחור, הכול מחלון אחד. הממשק כולו בעברית, מימין לשמאל, וגם באנגלית. העורך עצמו נשאר משמאל לימין, כמו שקוד צריך להיות.

אסמון מבוססת על [SASM](https://github.com/Dman95/SASM) של דמיטרי מנושין (GPL-3). מה שהשתנה:
- **Qt6**, ממשק שטוח ושקט, ערכה כהה ובהירה.
- **Command Palette** ‏(Ctrl+Shift+P), מצב ריכוז וסייר קבצים.
- **דיבאגר חדש על gdb/MI**, עם פאנלים להנדסה לאחור.
- **כלים מודרניים ארוזים בפנים:** GCC 16, GDB 18, NASM 3 ו-LLVM.
- **תפריט RE** שפותח את התוכנית ב-Ghidra, ‏Cutter, ‏x64dbg או ImHex.

## הורדה

בדף ה-[Releases](https://github.com/shealtieltehumim-prog/asmon/releases):

| קובץ | מה זה |
|---|---|
| `Asmon-x.y.z-Setup.exe` | מתקין אחד, שבו בוחרים רכיבים: בסיסית (כתיבה, הרצה ודיבוג) או מלאה (עם Ghidra, ‏Cutter, ‏x64dbg ו-ImHex). |
| `Asmon-x.y.z-portable.zip` | גרסה ניידת בלי כלי ה-RE: מחלצים ומריצים את `asmon.exe`. ההגדרות נשמרות בתיקייה `data` שליד התוכנה. |
| `Asmon-x.y.z-RE-tools-portable.zip` | כלי ה-RE לגרסה הניידת: לחלץ לתוך התיקייה `tools` שליד `asmon.exe`. |

### אזהרה של Windows בזמן ההתקנה
המתקין לא חתום דיגיטלית (חתימת קוד עולה כסף), ולכן Windows SmartScreen יציג "Windows protected your PC". כדי להמשיך: **More info ← Run anyway**. הקוד כולו פתוח, וכל קובץ נבנה ב-GitHub Actions מהקוד שבריפו הזה.

## מה יש בפנים

**כתיבה והרצה**
- **בנה והרץ:** F9. בנה בלבד: Ctrl+F9.
- **שגיאות ברורות:** שם הקובץ ומספר השורה, ודאבל-קליק על שגיאה קופץ לשורה.
- **פרויקטים מרובי קבצים** עם `%include` (מקבצים שליד הקובץ).
- **תבניות:** קובץ ← חדש מתבנית (Hello world ל-Windows, ל-Windows API ולינוקס).
- **תוצרי בנייה** ‏(Ctrl+Shift+B): listing של NASM, דיסאסמבלי (Intel), ‏hex וכותרות (`objdump -x`).

**דיבוג** (F5)
- **צעדים:** לפי שורה (F10 / F11), יציאה מפונקציה (Shift+F11) והוראה בודדת (Ctrl+F11).
- **נקודות עצירה:** F8, או לחיצה על מספר השורה.
- **פאנלים:**
  - **אוגרים:** השינויים מסומנים, הדגלים מפוענחים, ואפשר לערוך ערכים.
  - **זיכרון:** hex ו-ASCII מכל כתובת, תווית או `[rbp-8]`, עם עריכה.
  - **מחסנית**, ו**דיסאסמבלי** בתחביר Intel.
  - **מעקב (Watch):** ביטויים עם סוג וגודל.
- **קריסה** (למשל SIGSEGV): הדיבאגר עוצר על השורה שגרמה לה, עם הודעה ברורה.

**לינוקס**
- ב-Windows אפשר לבחור את היעד "Linux ELF ‏(WSL)". הבנייה לא צריכה WSL (‏NASM ו-ld.lld), אבל ההרצה כן.
- "בנייה ← התקן WSL" מתקין אותו.

**RE**
- התפריט פותח את התוכנית שבנית, או כל קובץ אחר, ב-Ghidra, ‏Cutter, ‏x64dbg או ImHex.

## הגדרות
- **ערכת נושא:** תצוגה ← ערכת נושא כהה.
- **שפה:** תצוגה ← Switch to English.
- **קובץ ההגדרות:** הכול נשמר בקובץ טקסט קריא, `Asmon.ini`. ב-Windows הוא ב-`%APPDATA%\Asmon\`, ובגרסה הניידת ב-`data\Asmon\` שליד התוכנה.
- **אסמבלרים נוספים:** NASM הוא ברירת המחדל. GAS, ‏FASM ו-MASM נמצאים תחת "הצג אסמבלרים נוספים" בהגדרות. MASM לא נארז, כי הוא של Microsoft.

## בנייה מהקוד

**לינוקס:**
```
sudo apt install qt6-base-dev qt6-svg-dev qt6-tools-dev-tools nasm gdb gcc-multilib
mkdir build && cd build && qmake6 ../asmon.pro && make -j
```
**Windows:** ראו `.github/workflows/build.yml` (‏MSYS2 UCRT64 עם Qt6, ואחר כך הורדת הכלים ובניית המתקין).
