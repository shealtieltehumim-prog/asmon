# אסמון — סביבת פיתוח לאסמבלי, בעברית

אסמון היא סביבת פיתוח מינימלית לאסמבלי: כותבים, בונים, מריצים, מדבגים ועושים הנדסה לאחור, הכול מחלון אחד. הממשק כולו בעברית, מימין לשמאל, וגם באנגלית. העורך עצמו נשאר משמאל לימין, כמו שקוד צריך להיות.

אסמון מבוססת על [SASM](https://github.com/Dman95/SASM) של דמיטרי מנושין (GPL-3). מה שהשתנה:
- **Qt6**, ממשק שטוח ושקט, ערכה כהה ובהירה.
- **Command Palette** ‏(Ctrl+Shift+P), מצב ריכוז וסייר קבצים.
- **דיבאגר חדש על gdb/MI**, עם פאנלים להנדסה לאחור.
- **כלים מודרניים ארוזים בפנים:** GCC 16, GDB 18, NASM 3 ו-LLVM.
- **תפריט RE** שפותח את התוכנית ב-Ghidra, ‏Cutter, ‏x64dbg או ImHex.

## הורדה

בדף ה-[Releases](https://github.com/shealtieltehumim-prog/asmon/releases):

| קובץ | מה זה |
|---|---|
| `Asmon-x.y.z-Setup.exe` (כ-125MB) | **מתקין אחד, קטן יחסית, בלי בחירת רכיבים.** יש בו הכול לכתיבה, בנייה, הרצה, דיבוג והנדסה לאחור: אסמון, NASM, המקשר (MinGW-w64 ל-x64, כולל gdb), מנוע הדיבוג המקורי, המפרק (דיסאסמבלי) והמפענח. אין צורך להתקין שום דבר נוסף. |
| `Asmon-x.y.z-portable.zip` (כ-198MB) | אותו תוכן בגרסה ניידת: מחלצים ומריצים את `asmon.exe`. ההגדרות נשמרות בתיקייה `data` שליד התוכנה. |
| `Asmon-x86-tools.zip` (אופציונלי, כ-162MB) | כלי 32 ביט (MinGW-w64 i686) לתוכניות x86. לחלץ לתוך תיקיית אסמון, כך שתיווצר התיקייה `MinGW`. |
| `Asmon-LLVM-tools.zip` (אופציונלי, כ-73MB) | LLVM (‏lld, ‏llvm-objdump, ‏lldb) לבניית תוכניות לינוקס בלי WSL. לחלץ לתוך תיקיית אסמון, כך שתיווצר התיקייה `LLVM`. |
| `Asmon-RE-tools.zip` (אופציונלי, כ-949MB) | כלי RE חיצוניים לתפריט RE: ‏Ghidra עם JDK, ‏Cutter, ‏x64dbg ו-ImHex. לחלץ לתוך התיקייה `tools` שבתיקיית אסמון. |
| `Asmon-x86_64.AppImage` | לינוקס: מסמנים כקובץ הרצה (`chmod +x`) ומריצים. NASM,‏ GCC ו-GDB באים מהמערכת: `sudo apt install nasm gcc gdb`. דורש הפצה מ-2024 ואילך (למשל Ubuntu 24.04). |

לכל קובץ יש קובץ `.sha256` ליד (פורמט `hash  שם-קובץ`). לבדיקה ב-PowerShell: `Get-FileHash <קובץ> -Algorithm SHA256` ולהשוות למה שכתוב בקובץ ה-`.sha256`.

### אזהרה של Windows בזמן ההתקנה
המתקין לא חתום דיגיטלית (חתימת קוד עולה כסף), ולכן Windows SmartScreen יציג "Windows protected your PC". כדי להמשיך: **More info ← Run anyway**. הקוד כולו פתוח, וכל קובץ נבנה ב-GitHub Actions מהקוד שבריפו הזה.

## מה יש בפנים

**כתיבה והרצה**
- **בנה והרץ:** F9. בנה בלבד: Ctrl+F9.
- **שגיאות ברורות:** שם הקובץ ומספר השורה, ודאבל-קליק על שגיאה קופץ לשורה.
- **פרויקטים מרובי קבצים**, בשתי דרכים:
  - `%include` של קבצים שליד הקובץ.
  - **מודולים נפרדים:** קובץ ← "קובץ פרויקט" יוצר `asmon.project` שמפרט קובצי `.asm` נוספים. כל מודול עובר אסמבלי בנפרד, והכול מקושר יחד. אפשר ללחוץ F9 מכל מודול, ושגיאה במודול אחר נפתחת בקובץ הנכון. אפשר להוסיף דגלים: `assembler-flags: -DDEBUG`,‏ `linker-flags: -lm`.
- **תבניות:** קובץ ← חדש מתבנית (Hello world ל-Windows, ל-Windows API ולינוקס).
- **תוצרי בנייה** ‏(Ctrl+Shift+B): listing של NASM, דיסאסמבלי (Intel), ‏hex וכותרות (`objdump -x`).
- **מסך נקי:** הכפתורים נמצאים בשורת התפריטים. פלט, קלט, יומן בנייה ותוצרי בנייה הם לשוניות בפאנל התחתון, ושורת המצב מציגה שורה ועמודה, אסמבלר, מצב ויעד.
- **ניווט בקוד:**
  - מעבר להגדרה של תווית, נתון או מאקרו (F12 או Ctrl+לחיצה). עובד גם לתוויות מקומיות (`.loop`), וגם למאקרו בתוך io64.inc.
  - כל השימושים (Shift+F12).
  - מעבר לתווית (Ctrl+Shift+O) ומעבר לשורה (Ctrl+G).
- **חיפוש בכל קבצי התיקייה** ‏(Ctrl+Shift+F), עם רישיות, מילה שלמה וביטוי רגולרי.
- **השלמה אוטומטית** של פקודות, אוגרים, הנחיות, מאקרו של io64.inc והתוויות של הקובץ. Tab או Enter מקבלים, ו-Ctrl+רווח פותח את הרשימה.
- **פונטים:** ‏JetBrains Mono לקוד ו-Rubik (עגול, עם עברית) לממשק. שניהם מוטמעים בתוכנה, אין צורך להתקין.
- **שגיאות מסומנות בקוד:** נקודה אדומה ליד מספר השורה, קו גלי מתחת לפקודה, וההודעה בריחוף.
- **עברית בקוד:** מחרוזות והערות בעברית מוצגות בסדר הנכון.
- **קבצים אחרונים** במסך הפתיחה.
- **פאנל תחתון** ‏(Ctrl+J): יומן בנייה, קונסולת דיבוג (פקודות gdb), ו**טרמינל משולב** ‏(Ctrl+\`) שנפתח בתיקיית הקובץ, עם NASM ו-MinGW כבר ב-PATH.

**דיבוג** (F5)
- **צעדים:** לפי שורה (F10 / F11), יציאה מפונקציה (Shift+F11) והוראה בודדת (Ctrl+F11).
- **נקודת עצירה מותנית** (Ctrl+Shift+F8): למשל `rcx == 5`. מסומנת בטבעת כתומה.
- **עצירה על כתיבה לזיכרון:** בלשונית "מעקב", כפתור "עצור כשנכתב". ביומן מופיעים הערך הישן והחדש.
- **מחסנית קריאות:** לשונית "קריאות". דאבל-קליק קופץ לשורה (גם בקובץ אחר של הפרויקט).
- **פרויקט של כמה קבצים:** צעדים, נקודות עצירה ומחסנית הקריאות עובדים בכל קובצי `asmon.project`. ‏F11 על `call` לפונקציה שבמודול אחר פותח את הקובץ שלה, ו-Shift+F11 חוזר.
- **התחברות לתהליך שרץ** (דיבוג ← "התחבר לתהליך..."): בוחרים תהליך מהרשימה, והדיבאגר עוצר אותו במקום שבו הוא נמצא. תוכנית שנבנתה באסמון מופיעה ראשונה, ואיתה יש גם שורות, נקודות עצירה וצעדים. בכל תהליך אחר הדיבוג הוא לפי פקודות מכונה. עצירה (Shift+F5) מנתקת את הדיבאגר, והתהליך ממשיך לרוץ.
- **נקודות עצירה:** F8, או לחיצה על מספר השורה.
- **פאנלים:**
  - **אוגרים:** השינויים מסומנים, הדגלים מפוענחים, ואפשר לערוך ערכים.
  - **זיכרון:** hex ו-ASCII מכל כתובת, תווית או `[rbp-8]`, עם עריכה.
  - **מחסנית**, ו**דיסאסמבלי** בתחביר Intel.
  - **מעקב (Watch):** ביטויים עם סוג וגודל.
- **קריסה** (למשל SIGSEGV): הדיבאגר עוצר על השורה שגרמה לה, עם הודעה ברורה.

**לינוקס**
- ב-Windows אפשר לבחור את היעד "Linux ELF ‏(WSL)" בשורת המצב שבתחתית החלון. הבנייה לא צריכה WSL (‏NASM ו-ld.lld), אבל ההרצה כן.
- **דיבוג תוכנית לינוקס מתוך Windows:** F5 מפעיל את gdb בתוך WSL, עם כל הפאנלים. אם gdb לא מותקן ב-WSL, אסמון מציע להתקין אותו בטרמינל.
- "בנייה ← התקן WSL" מתקין אותו.

**32 ביט (x86) ב-Windows**
- רכיב נפרד במתקין (בהתקנה המלאה): ‏MinGW-w64 i686 עם GCC ו-gdb. בוחרים x86 בהגדרות.

**RE**
- התפריט פותח את התוכנית שבנית, או כל קובץ אחר, ב-Ghidra, ‏Cutter, ‏x64dbg או ImHex.

## הגדרות
- **ערכת נושא:** תצוגה ← ערכת נושא כהה.
- **קיצורי מקשים:** הגדרות ← "קיצורי מקשים". יש חיפוש, אזהרה על קיצור כפול, וכפתור החזרה לברירת המחדל. הקיצורים נשמרים בקטע `[shortcuts]` שבקובץ ההגדרות.
- **שפה:** תצוגה ← Switch to English.
- **קובץ ההגדרות:** הכול נשמר בקובץ טקסט קריא, `Asmon.ini`. ב-Windows הוא ב-`%APPDATA%\Asmon\`, ובגרסה הניידת ב-`data\Asmon\` שליד התוכנה.
- **אסמבלרים נוספים:** NASM הוא ברירת המחדל. GAS, ‏FASM ו-MASM נמצאים תחת "הצג אסמבלרים נוספים" בהגדרות. GAS ו-FASM נבדקים ב-CI ב-64 וב-32 ביט. MASM לא נארז, כי הוא של Microsoft.

## בנייה מהקוד

**לינוקס:**
```
sudo apt install qt6-base-dev qt6-svg-dev qt6-tools-dev-tools nasm gdb gcc-multilib
mkdir build && cd build && qmake6 ../asmon.pro && make -j
```
**Windows:** ראו `.github/workflows/build.yml` (‏MSYS2 UCRT64 עם Qt6, ואחר כך הורדת הכלים ובניית המתקין).
